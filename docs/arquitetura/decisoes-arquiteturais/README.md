## Convenção de status
- `Proposto`: em discussão.
- `Aceito`: aprovado pela equipe.
- `Rejeitado`: alternativa avaliada e descartada.
- `Substituído`: decisão antiga substituída por outra ADR.

Não marcar como `Aceito` apenas porque o arquivo foi criado. A aprovação deve ser formalizada pela equipe no ADR correspondente.
